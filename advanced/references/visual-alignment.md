# 先定位台词，再看帧检查动作

`duanju_slice_cut` 或修订启动后，以内部 `proposal` 指定完整台词，立即执行 `duanju_slice_advanced` 的 `locate`。不生成 Word，也不等待方案审批。

```json
{
  "action": "locate",
  "workDir": "<duanju_slice_cut 返回的独立任务目录>",
  "data": { "concurrency": 6, "minScore": 0.65, "force": false }
}
```

- `concurrency` 为 1–8 的整数，默认 6；按集并行。`provider/model` 可指定支持图片输入的视觉模型，省略则沿用插件配置与现有默认路由。`minScore` 为视觉置信度阈值，范围 0.65–1，默认 0.65。`force:true` 才整体重查；平常已通过的对白直接复用、转写走缓存。
- **字幕优先**：读对应集可用的 UTF-8 `.srt`。用一条或多条完整、相邻字幕条匹配，取首条开始与末条结束时间，不推算条内词句的时间。剧本与字幕语言不同时，仍以 `source_line_id/quote_zh` 标识剧本对白；能从该集 `.srt` 找到对应完整原句时填 `subtitle_quote`，再视觉核对场景与剧情。
- **自动回退到 ASR**：该集 SRT 缺失、无效、不可用，或某句完整台词未可靠匹配时，无需确认，直接用 Slice 原有的火山语音识别。未选字幕目录则直接走 ASR。每次 `locate` 对每个需要的集最多转写一次，只用转写结果匹配未定位的完整台词或对应完整译句，不改字幕命中。合并分句里的子句需有词级时间，不猜其它集或时间。
- 两路都在可靠定位后抽帧：从台词附近开始，以 5 fps 连续查看短窗，台词之后最多检查 4 秒；最多三处相近锚点由画面消歧。对白时间向外保全到 30 fps。视觉请求逐窗只核对对应场景与紧接动作，不用新镜头补齐动作、不全片扫描；同一请求可合并多个互不相关的窗口，但各窗口的证据不能互相顶替。连续跨窗核对重叠画面。
- 一次视觉请求合并多个互不相关的局部窗口（默认 2–3 个，受单请求图片上限约束，每窗 4–20 帧）。请求以 `窗口 jN｜…` 分节，模型须按 `{"reviews":[{"id":"j1",…}]}` 逐窗返回，覆盖全部窗口 id 且不重复；缺项、重复或整批返回无法解析时该批窗口判定为无效，不采用。`reviewer` 字段为 `llm-batch`。
- 未见正文末或相关动作仍在继续时继续看窗；没有后续动作则保留完整正文（`no-action`）；相关同镜头动作结束取证据支持的终点（`action-complete`）；若被正文后的切镜打断，在新镜头前截止（`shot-cut`）。无法确认角色、场景、动作终点或切镜时不采用该候选，不截断台词。只因画面核验未通过，不会把已有字幕锚点换成 ASR。

## 回填证据

- 读 `tmp/dialogue-alignment.json`。`segments` 仅列通过验收的对白，包含 `segment_index`（当前定位目标的 0 起始段位）、集号、原稿引文、边界及实际 5 fps 清单。每条按实际来源记录 `alignment.subtitle_anchor`（`file/sha256/cueIds` 和完整字幕时段）或 `alignment.asr_anchor`；同集可以有两种来源。整个对白项用于执行，不手改边界、段位或证据，不把这组对白替代完整 `plan.segments`。
- 报告为 `incomplete` 时可用其中验收通过的对白；重试缺项或换用已核实素材。如 ASR 已转写但没匹配到剧本台词，读返回的 `alignmentFile` 中 `sources[].asr.transcriptFile`，找到同一句完整原文才补 `asr_quote`；已有 `subtitle_quote` 也可作为 ASR 同语提示，不是字幕证据。直接 `proposal → locate` 复用转写缓存，不询问用户、不手填时间。新增或更换对白同样走 `proposal → locate`，原有证据要对应当前计划与台词来源；手工采样及旧纯视觉定位不能替代锚点。
- 同一条对白在一轮内已通过（有连续 5 fps 覆盖）时，后续 `proposal → locate` 直接复用，不再抽帧或复核；只有缺项、新增台词或 `force:true` 才重新定位。复用不影响 `plan` 里原样引用该对白及其 `alignment`。

## 快切抽帧检查（与对白核验独立）

- `locate_montage` 先从同集 SRT 定位附近锚句，字幕缺失、无效或未匹配时复用该集 ASR 时间轨。只搜索锚句指定侧紧邻的无对白空档，上限 10 秒，不越过其他台词。例如锚句在 34–37 秒、上一句到 28 秒结束，找说话前的看表动作就只抽 `[28,34)`。多个匹配无法消歧时不猜选。
- 在这个空档内每秒抽 3 帧。按顺序用同一组样本确认目标动作并检查字幕、封面、原片切镜、跳帧、闪镜和卡帧。不相关、异常或无法确认的帧会断开候选范围；至少两张连续通过的样本才能形成候选，范围不向最后一张样本之后延长。
- `save_plan`、`sync` 和 `validate` 只验源范围是否仍在同一个已通过区间，不再抽帧。`picture/continuation` 不做快切检查。短于采样间隔、恰好落在两张样本之间的异常可能漏检。
- 成片不再逐帧做视觉检查；混剪仍校验 MP4 是否可解码及其时长、尺寸和音轨。
