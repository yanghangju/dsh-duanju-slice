# 短剧切片工作台（dsh-duanju-slice）

## 首次运行

安装后打开「切片工作台」，点击「配置运行环境」。工作台先检查火山引擎豆包语音 API Key 是否已配置；没有找到时会弹窗，保存密钥后再继续。助手在专用配置会话中加载内置的 `duanju-slice-runtime` Skill，通过后台任务检查 Python（含 `librosa==0.11.0` 和卡点依赖）、FFmpeg（含 `libx264`、AAC）和 FFprobe，能用就沿用本机环境。若本机 Shell 需要安装权限，请按提示审批。

如果配置还没完成，直接在原配置对话里回复「请继续配置运行环境」即可续跑，不需要另开会话或重新提供请求 ID。只有原请求不可用时，才需要点「重新配置环境」另开一条配置对话，原记录保留。进入剪辑工作台后，可点右上角的齿轮，在旁边的菜单选「修改语音识别key」，填写或更换密钥，不需要重新配置运行环境。

工作台保存的密钥保存在本机 DSH 凭据库中，不显示旧值，也不写入对话、剪辑方案或会话配置。它优先于插件的 `volcApiKey` 配置和 `VOLCENGINE_API_KEY`、`VOLC_API_KEY` 环境变量。首次配置只检查是否存在密钥，不向语音服务发请求；服务在实际识别时才验证密钥。

- 没有合格的 Python 时，从官方 NuGet 下载 CPython，依赖优先从清华 PyPI 镜像获取，失败则尝试官方 PyPI。缺少 FFmpeg 或 FFprobe 时，从 [GitHub 运行时仓库](https://github.com/yanghangju/runtime) 下载固定版本文件。自动安装这些工具仅支持 **Windows x64**，不修改系统 Python 或 PATH；其他平台请先准备本机环境。
- 默认曲库不随插件发布。首次配置（包括从旧版升级且尚无缓存时）从同一 GitHub 运行时仓库下载固定版本，验证目录汇总和音频后缓存到 `~/.dsh/plugins/dsh-duanju-slice/`。即使本机工具都可用也会补齐曲库，后续复用缓存。下载和解压使用 `curl` 和 `tar`（Windows 自带），不需要 Git。
- 下载优先沿用 `HTTPS_PROXY`、`HTTP_PROXY`、`ALL_PROXY` 或 Windows 当前用户的代理，并保留 `NO_PROXY` 规则。下载失败会在当前任务内自动尝试直连和内置备用源，不改系统代理，不跳过文件校验。所有可用下载途径失效时才报告尝试结果。

配置对话结束后，工作台自动验证，无需手动重查。验证通过后点击「新建会话」开始剪辑，下次打开会跳过配置页。发布包继续内置固定片尾素材。

## 检查插件更新

在切片工作台右上角点齿轮，在菜单选「检查更新」。更新对话框打开后自动检查 [GitHub Releases](https://github.com/yanghangju/dsh-duanju-slice/releases) 的最新正式版本；有新版时会显示当前版本、新版和发布说明。点「取消」不会下载或安装。

结束正在进行的剪辑后再点「立即更新」。工作台先下载并校验对应的 `.tgz`，再由 DeepSeek Harness 卸载旧包并解包安装新版。对话、密钥、运行环境和成片不受影响；开发目录的链接只会被解除，不会删除源代码。如果提示需要重启，请重启 DeepSeek Harness。检查和安装都不调用 AI。

## 开始剪辑

在「切片工作台」先选**混剪**或**单集切片**，再选择剧本 DOCX、分集素材目录、成片保存目录并填写内容方向。锁定配置后点「生成初版」，或在对话中请求剪辑，不需要审批方案。要更改模式、素材或方向，请新建会话。

**视觉检查在选材阶段完成**，渲染后不再把成片逐帧交给视觉模型。混剪成片仍需通过解码、时长、画幅和音轨校验。已有成片不会被覆盖或自动重检。

### 单集切片

从一集原片里剪出一段连续画面，保留原顺序与原声，不加配乐、转场或片尾。可让助手按剧本和方向自动选段，或在对话中指定集号和原片秒数，例如「剪第 3 集 12.5 到 40 秒」，此时不需要语音识别。可生成 MP4；检测到可写的剪映草稿箱时也会保留可编辑草稿。修订时可说「开头提前两秒」，新版不会覆盖旧版。

选定的原集起点若在 **0–2 秒（含 2 秒）**，渲染前以 **每秒 3 帧**检查切片前 2 秒（不足 2 秒则检查整段）。检出独立封面或标题卡时，从其后的首个已确认非封面帧开始，保留原定结尾；MP4 和草稿使用同一切点。此检查也适用于手动切片和修订，需要当前模型支持图片输入；无法确认画面或剔除后不足 1 秒时，不输出新版本。很短且落在抽帧间隔内的封面可能漏检。

### 混剪（默认）

有分集字幕时可选填「字幕目录」。如果只需要方案，可明确请求「只出方案」。

1. **选了字幕目录**：优先用对应集 `.srt`（如 `EP01.srt`）的完整字幕条时间。字幕与剧本语言不同时，能在字幕中找到对应完整原句就引用该句。字幕缺失、无效、不可用或无法可靠匹配完整台词时，无需确认，自动用现有火山引擎语音识别定位未命中的台词；每个需要的集只转写一次，不改已匹配的台词。**未选字幕目录**：直接用语音识别。两种方式命中后都以 5 fps 抽帧，核验台词及紧接的同镜头动作；动作不确定的片段不采用。已通过的对白在重跑时直接复用，不重新抽帧。选快切镜头时，先定位同集附近的完整台词。例如「时间不早了」在 34–37 秒，找说话前的看表动作，就只在 34 秒前紧邻的无对白空档里搜索（遇到上一条对白即停止，最多 10 秒）。以 **每秒 3 帧**同时确认目标动作、字幕、闪镜、跳帧、卡帧和封面。卡点只能在已核验的连续范围内调整，不重复抽帧。落在采样间隔内的短暂异常可能漏检。
2. 从配置时下载的 Promo 曲库选一首 BGM，沿用原有拍点分析和同步逻辑。BGM 基础增益固定 **−12 dB**（约 0.2512），工作台和工具不再提供音量设置；原声、音效和淡入淡出规则不变。
3. **只用一份 `tmp/plan.json` 作为剪辑方案**，由它驱动成片与独立可编辑剪映草稿，不生成 Word。先渲染并回报 MP4 实际路径，确认后再导入剪映草稿；草稿登记失败时保留已通过技术校验的 MP4，只补登记。若剪映未刷新草稿列表，可重启剪映。

#### 混剪规格

- **铺垫 → 5–10 秒卡点快切 → 同故事线完整原声高潮 → 固定片尾**。允许跨集，快切使用连续单曲的真实重音、拍点与起音；全片含片尾不超过 50 秒。可在快切内安排短黑屏与同步静音，不延长时间或凑镜头。有旧快切基准的修订使用两倍不同镜头，不虚构基数。
- 对白抽帧核验和快切抽帧检查都需要支持图片输入的模型。需要语音识别而无法复用转写缓存时，会把所需集的音频发送到语音服务。首次配置不设置模型。无需外部 Skill 或另装 Promo 插件。
- 片尾从正文结束前 1.5 秒取帧，在正文结束处定格；原生「炫光」与完整「大气片尾声效」从结束前半个转场时长同时开始（默认转场 0.8 秒）。成片为 1080×1920 / 30 fps；草稿保留分段、独立音轨和原生转场，所引用的素材复制到草稿目录。

## 素材与版本

- 一集可用 `ep001.mp4`、`第2集.mov` 等文件，也可用 `ep003/` 子目录，由目录中的视频按文件名自然排序组成一集。只选剧本与视频共同具有的集数，所需多段集在任务目录内合并，不改原素材。
- `subtitleDir` 是可选绝对路径，例如 `D:\海外短剧\The Deadly Wedding Ring\字幕`。目录直接放分集 UTF-8 `.srt`。同集常规文件优先于 `(1)` 副本；无法唯一配对时不猜，用语音识别定位该集所选台词。多段集的字幕时间须以自然顺序拼成的整集为准；外部字幕只用来定位；快切选用抽样未见硬字幕的镜头，其他段落不移除已有硬字幕。
- 单集切片的 MP4 直接保存在所选目录。混剪每版各有一个 `高级剪辑-*` 目录，根目录保留 MP4 和 `tmp/`；其中的 `tmp/plan.json` 记录实际采用的段、对白、音乐与片尾。不要整目录删除 `tmp/`，它还含核验证据与正式依赖。
- 工作台可切换已有版本。修订生成新版本，不覆盖旧版。混剪可改剧情和选曲，但不靠截断完整原声对白或拆掉固定片尾来改时长。

## 工具与开发

| 操作 | 用途 |
| --- | --- |
| `duanju_slice_survey` | 只读查看集数、时长、音轨、剧本配对 |
| `duanju_slice_cut` / `duanju_slice_revise` | 直接启动新作或修订 |
| `duanju_slice_plan` | 仅交付标为 `plan_only` 的 `plan.json`，不定位、抽帧或导出 |
| `duanju_slice_advanced` | 内部取材、对白定位与画面核验、拍点、渲染及草稿登记 |
| `duanju_slice_versions` | 查看或切换版本，不改已交付文件 |

离线只读勘察：`node scripts/survey.mjs <短剧目录> [剧本.docx]`。执行规则见[高级工作流](<advanced/workflow.md>)。

本地验证可用 `npm test`。高级媒体回归使用合成素材、模拟语音和视觉模型、隔离曲库与草稿箱；结构、解码和登记验证不等于真实素材的听感或剪映界面播放验收。
