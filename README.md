# 短剧切片工作台（dsh-duanju-slice）

## 首次运行

安装后打开「切片工作台」，点击「配置运行环境」。助手在专用配置会话中加载内置的 `duanju-slice-runtime` Skill，通过后台任务检查 Python（含 `librosa==0.11.0` 和卡点依赖）、FFmpeg（含 `libx264`、AAC）和 FFprobe，能用就沿用本机环境。整个配置没有总时限；若本机 Shell 需要安装权限，请按提示审批。

配置未完成时，点击「运行环境配置」页右上角的「重新配置环境」，会切换到一个独立的新会话并在那里发送请求，不会在原会话重复发送。已进入剪辑工作台时，右上角的同名按钮也会另开配置会话，不影响当前剪辑。

- 没有合格的 Python 时，插件从官方 NuGet 下载 CPython，再用 `pip install -i https://pypi.tuna.tsinghua.edu.cn/simple` 指定清华 PyPI 镜像安装依赖。缺少 FFmpeg 或 FFprobe 时，从 [GitHub 运行时仓库](https://github.com/yanghangju/runtime) 下载对应的固定版本文件。自动安装这些工具仅支持 **Windows x64**，不修改系统 Python 或 PATH；其他平台请先准备本机环境。
- 默认曲库不随插件发布。首次配置（包括从旧版升级且尚无缓存时）从同一 GitHub 运行时仓库下载固定版本，验证目录汇总和音频后缓存到 `~/.dsh/plugins/dsh-duanju-slice/`。即使本机工具都可用也会补齐曲库，后续复用缓存。下载和解压使用 `curl` 和 `tar`（Windows 自带），不需要 Git。
- 下载前优先检查 `HTTPS_PROXY`、`HTTP_PROXY`、`ALL_PROXY`，在 Windows 上再检查当前用户的代理设置；沿用 `NO_PROXY` 绕过规则，未配置代理时直连。

验证通过后，下次打开会跳过配置页。按对话提示点击「新建会话」开始剪辑。发布包继续内置固定片尾素材。

## 开始剪辑

在「切片工作台」选剧本 DOCX、分集素材目录、成片保存目录，填写内容方向；有分集字幕时可选填「字幕目录」。锁定配置后点「生成初版」，或在同一会话请求剪辑，直接开剪，不等待方案审批。锁定后如要更改配置（含字幕目录），请新建会话。只想看方案时，可明确请求「只出方案」。

1. **选了字幕目录**：优先用对应集 `.srt`（如 `EP01.srt`）的完整字幕条时间。字幕与剧本语言不同时，能在字幕中找到对应完整原句就引用该句。字幕缺失、无效、不可用或无法可靠匹配完整台词时，无需确认，自动用现有火山引擎语音识别定位未命中的台词；每个需要的集只转写一次，不改已匹配的台词。**未选字幕目录**：直接用语音识别。两种方式命中后都以 5 fps 抽帧，核验台词及紧接的同镜头动作；动作不确定的片段不采用。已通过的对白在重跑时直接复用，不重新抽帧；非对白镜头不抽帧核验。
2. 从配置时下载的 Promo 曲库选一首 BGM，沿用原有拍点分析和同步逻辑。BGM 基础增益固定 **−5 dB**（约 0.5623），工作台和工具不再提供音量设置；原声、音效和淡入淡出规则不变。
3. **只用一份 `tmp/plan.json` 作为剪辑方案**，由它驱动成片与独立可编辑剪映草稿，不生成 Word。先渲染并回报 MP4 实际路径，确认后再导入剪映草稿；草稿登记失败时保留已通过解码校验的 MP4，只补登记。若剪映未刷新草稿列表，可重启剪映。

## 剪辑规格

- **铺垫 → 5–10 秒卡点快切 → 同故事线完整原声高潮 → 固定片尾**。允许跨集，快切使用连续单曲的真实重音、拍点与起音；全片含片尾不超过 50 秒。可在快切内安排短黑屏与同步静音，不延长时间或凑镜头。有旧快切基准的修订使用两倍不同镜头，不虚构基数。
- `locate` 的抽帧核验需要支持图片输入的模型。需要语音识别时（未选字幕目录或字幕未能定位全部目标台词）需配置 `VOLCENGINE_API_KEY`、`VOLC_API_KEY` 或插件的 `volcApiKey`；无法复用转写缓存时会向该服务发送所需集的音频。首次运行的本机环境配置不设置模型。无需外部 Skill 或另装 Promo 插件。
- 片尾从正文结束前 1.5 秒取帧，在正文结束处定格；原生「炫光」与完整「大气片尾声效」从结束前半个转场时长同时开始（默认转场 0.8 秒）。成片为 1080×1920 / 30 fps；草稿保留分段、独立音轨和原生转场，所引用的素材复制到草稿目录。

## 素材与版本

- 一集可用 `ep001.mp4`、`第2集.mov` 等文件，也可用 `ep003/` 子目录，由目录中的视频按文件名自然排序组成一集。只选剧本与视频共同具有的集数，所需多段集在任务目录内合并，不改原素材。
- `subtitleDir` 是可选绝对路径，例如 `D:\海外短剧\The Deadly Wedding Ring\字幕`。目录直接放分集 UTF-8 `.srt`。同集常规文件优先于 `(1)` 副本；无法唯一配对时不猜，用语音识别定位该集所选台词。多段集的字幕时间须以自然顺序拼成的整集为准；已有原片硬字幕照常保留，外部字幕只用来定位。
- 每版各有一个 `高级剪辑-*` 目录，根目录保留 MP4 和 `tmp/`；其中的 `tmp/plan.json` 记录实际采用的段、对白、音乐与片尾。不要整目录删除 `tmp/`，它还含核验证据与正式依赖。
- 工作台可切换已有版本。修订直接生成新版本，旧版不变；可改剧情和选曲，但不靠截断完整原声对白或拆掉固定片尾来改时长。更换素材或基础方向时请新建会话。

## 工具与开发

| 操作 | 用途 |
| --- | --- |
| `duanju_slice_survey` | 只读查看集数、时长、音轨、剧本配对 |
| `duanju_slice_cut` / `duanju_slice_revise` | 直接启动新作或修订 |
| `duanju_slice_plan` | 仅交付标为 `plan_only` 的 `plan.json`，不定位、抽帧或导出 |
| `duanju_slice_advanced` | 内部取材、对白定位与画面核验、拍点、渲染及草稿登记 |
| `duanju_slice_versions` | 查看或切换版本，不改已交付文件 |

离线只读勘察：`node scripts/survey.mjs <短剧目录> [剧本.docx]`。执行规则见[高级工作流](<advanced/workflow.md>)。

本地验证可用 `npm test`。高级媒体回归使用合成素材、模拟语音和视觉模型、隔离曲库与草稿箱；结构、解码和登记验证不等于真实素材的听感或剪映界面播放验收。
